# EasyDownloader

Paste a link, pick a format, download.

- YouTube → MP3 at 128 / 192 / 320 kbps
- YouTube → MP4 at 360p / 720p / 1080p
- Instagram reels and posts (public ones)

Files land in `Downloads/EasyDownloader`.

Built on `youtubedl-android` (yt-dlp + ffmpeg). If YouTube changes something,
the library needs an update — push a new version and rebuild.

Use it only for content you own or are allowed to download.
